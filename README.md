## 二、WebDAV 书库双向同步

### 解决的问题

原版 WebDAV 只能手动「备份 / 恢复」一个整包。实际使用中会出现：

- 换设备 / 重装后，云端有书、本地没有，只能整包恢复覆盖本地，风险大；
- 本地删掉的书，云端文件永远留着；
- 不知道上次同步是什么时候。

本分支把同步粒度**下沉到单本书的文件级**，增量、可追溯。

### 配置入口

`设置 → 备份与恢复 → WebDAV 设置`

| 项 | 说明 |
|----|------|
| WebDAV 地址 | 例如 `https://dav.example.com/remote.php/dav/files/user/` |
| 账号 / 密码 | Basic Auth |
| 子目录 | 可选，多账号隔离用 |
| 设备名称 | 日志按设备分目录；留空用设备型号 |

### 云端目录结构

```
<WebDAV 根>/
├── books/                 # 书籍文件，扁平存放，按文件名去重
│   ├── 三体.epub
│   └── 明朝那些事儿.txt
└── logs/
    ├── <设备A>/
    │   ├── appLog.log
    │   └── crash/
    └── <设备B>/
```

扁平结构是刻意的：不做「作者 / 书名」分层，避免改名后产生同一本书两份。

### 五个开关

| 设置项 | 默认 | 作用 |
|--------|------|------|
| 导入后自动上传 | 开 | 本地导入书籍后立刻上传到 `books/` |
| 删除时同步删除远程文件 | 开 | 删除本地书籍时删除云端同名文件（**真删，不保留**） |
| 书籍双向同步 | 开 | 定时对账：云端有本地没有 → 下载；本地有云端没有 → 上传 |
| 恢复缺失的本地书 | 关 | 只做「缺失补齐」，不上传不删除，最保守的档位 |
| 日志同步到 WebDAV | 开 | 应用日志 + 崩溃日志上传到 `logs/<设备>/`，需先开启「记录日志」 |

### 去重、冲突、删除规则

- **去重口径**：只认**文件名**（含扩展名），同名即视为同一本书。
- **冲突裁决**：同名文件比较**修改时间**，谁新谁赢；不做内容哈希比对。
- **超长文件名**：按字节截断，保留扩展名并追加短哈希，避免 WebDAV 端文件名超限。
- **删除**：真删，无回收站 / 软删除。**只有用户主动删除**才会推送远程删除，同步过程不会误删。
- **离线补偿**：删除失败（远端离线）时写入待删队列，下次同步补做，直到成功。
- **同步周期**：每 5 分钟自动对账一次；书架菜单也可手动触发。
- **落地位置**：同步下来的书写入**应用私有目录**，不会出现「没有权限访问 / 请选择文件夹」。

### 两台设备各有本地书，云端最终几本？

设备 A 有 10 本、设备 B 有 15 本、交集 5 本 → 去重后云端 10 + 15 − 5 = **20 本**。
交集部分按修改时间取新的一方，不是「以谁为准」，而是两边并集。

### 阅读进度

进度 JSON 增加 `bookKey`（书库相对路径）与 `bookUrl` 双键，解决「同名不同书」和「同名同书跨设备」的进度串号。

## 三、共享书库（多端主从）

### 解决的问题

局域网里多台设备想共用一份书库：一台主设备存文件，其余设备只读取和记录进度，不重复占空间。

```
主设备：局域网共享程序（HTTP）
         /getBookshelf  /getChapterList  /getBookContent  /progress
              ↑                    ↑
       从设备 A          从设备 B / C ……
   Legado 把主设备当「共享书库」数据源 + 书架镜像
```

### 一次同步做什么

启动时依次执行：

1. 拉取书架 → 补齐本地没有的书（来源统一标记为 `共享书库`）
2. 同步目录
3. 上报本地进度
4. 同步删除

结束后返回一行结果提示（新增 / 移除 / 目录 / 进度四项统计）。

### 行为

| 行为 | 实现 |
|------|------|
| 本地读完一章 | 推送进度到主设备 |
| 主设备进度更新 | 拉回本地，覆盖本地旧进度 |
| 删除书 | 通知主设备，由主设备负责实际删除 |

> 这是本分支独有功能，上游没有，合并上游时注意别被覆盖。

## 四、Web 阅读器重构

### 打开方式

App 内开启 Web 服务（设置 → 其他设置 → Web 服务），浏览器访问 `http://<手机IP>:1122/`。

### 修掉的坑

| 现象 | 根因 | 修复 |
|------|------|------|
| 第一章 13/14 再翻变成第二章 1/21，**14/14 永远看不到** | 分栏模式下末页被判成「没有剩余空间」，直接甩到下一章 | 章末补齐空白列，14/14 正常出现，末页进度 100%，再甩动才进下一章 |
| 章末先出现一页空白，再翻才是下一页 | 视口上下留白未计入分栏高度，末行被视口底边裁切 | 分栏翻页补齐上下留白 |
| 8/8 时进度条的圆没顶满 | 进度按「可用列数」计算 | 末页归一到 100% |
| 改设置必须整页刷新才生效 | 重排入口分散，字体 / 边距多个来源互相覆盖 | 设置改动即时重排，页边距由单一来源控制 |
| 点「配置点击区域」直接弹窗，翻不了页 | 点击区域按钮与翻页热区冲突 | 点击区域改独立弹窗 |

### 三种阅读方式

- **上下滚动**（连续）：补章 / 裁章时补偿滚动位置，重新分段并记忆位置。
- **左右翻页**：CSS 分栏 + 甩动翻页。
- **点击翻页**：点左 / 右区域翻页，与工具栏热区互不干扰。

### 覆盖式上下栏（对齐 App 内阅读）

- 顶部 / 底部栏是**覆盖层**，默认隐藏；
- 点击正文显示，再点空白处隐藏；
- 显示 / 隐藏**不触发正文重新排版**，正文位置不跳；
- 工具栏呼出后仍可左右 / 上下滑动翻页；
- 底部常驻一行小字**全书百分比**进度。

### 设置面板

折叠分组：主题（含亚麻纸配色）/ 字体（可选系统已安装字体）/ 版式与页边距（滑杆）/ 阅读方式。
顶部显示书名，点击可直接改名。

### 书架

- 网格 / 列表视图切换
- 书名清洗：去掉 `[sxsy.org]` 之类推广标签，全角【转半角 [
- 内置 14 章 demo 书，没导书也能直接体验阅读器

## 五、本地书导出修复

### 现象

导出的 txt **只有第一页 / 只有书头**，后面全空；本地导出和 WebDAV 导出都一样。

### 根因

导出依赖书籍的章节表。本地导入的书如果**从没打开过**，章节表是空的；旧逻辑遇到空章节表直接跳过解析，把书头写完就收尾 → 文件残缺。
附带第二个问题：章节计数把书头也算进去，导致「看起来导了几章」其实没有正文。

### 修复

1. 章节表为空 → **强制重新解析目录**（即使本地修改时间没变）。
2. 只有**真正取到章节正文**才计入章节数，书头不计入。
3. 一章正文都没取到 → 报错并删除残缺文件，不再静默产出空书。

## 九、常见问题

| 症状 | 排查 |
|------|------|
| 清空本地书后同步不回来 | 确认「书籍双向同步」开着；重进一次设置页让偏好写入；或在书架菜单手动触发同步 |
| WebDAV 下拉刷新没反应 | 书籍同步不是下拉刷新，是每 5 分钟定时 + 手动触发 |
| 同步下来打不开 / 提示没权限 | 书应落在应用私有目录；确认安装的是本仓库构建的 APK |
| 云端删了文件但本地还在 | 反向删除只对「本地主动删」生效，云端删除不会反向删本地（防误删） |
| 恢复服务器配置报 `bad padding` | 密码解密失败，重输 WebDAV 密码即可 |
| WebDAV 日志目录是空的 | 先在设置里开启「记录日志」，再触发一次日志同步 |
| 网页端和 App 进度不一致 | 确认两端都开了进度同步；旧进度无 `bookKey` 的会在首次同步后补写 |

## 十、已知限制

- WebDAV 冲突只按**修改时间**裁决，不看内容哈希；两边同时改同一本书时，慢的一方会被覆盖。
- `books/` 是扁平目录，同一本书改名后会被当成两本。
- 删除开关默认开启，"全选删除"会连云端书库一起清空，没有软删除兜底。
- 共享书库依赖局域网共享程序在线，主设备离线时从设备只能读本地缓存。
- Web 阅读器是浏览器实现，排版细节无法做到与 App 内阅读像素级一致。
